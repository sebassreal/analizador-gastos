# Analizador de Gastos 💰

Herramienta web desarrollada en Python y Flask para analizar gastos personales de forma simple y visual.

## ¿Qué hace?
- Subir resumen de gastos en Excel o CSV
- Tipear gastos manualmente
- Ver el total gastado y gasto promedio
- Analizar gastos por categoría con barras visuales
- Identificar en qué categoría gastás más

## Tecnologías utilizadas
- Python
- Flask
- Pandas
- HTML / CSS / JavaScript

## Archivos
- `app.py` — servidor web Flask
- `datos_prueba.py` — generador de datos de ejemplo
- `templates/index.html` — interfaz web

## Cómo correrlo
1. Instalar dependencias: `pip install flask pandas openpyxl`
2. Correr: `python app.py`
3. Abrir en el navegador: `http://127.0.0.1:5000`
